# SharpTUI plugin privacy

The SharpTUI plugin is a skills-only package. It has no hosted service,
authentication, telemetry, advertising, or developer-operated data storage.

The plugin provides local instructions and scripts that help ChatGPT and Codex
write and verify SharpTUI applications. Those scripts read the bundled API
catalog and, when explicitly run, local project files and terminal output. They
do not transmit data to the SharpTUI developer.

Your use of ChatGPT, Codex, GitHub, and the local execution environment remains
subject to those services' privacy terms and the permissions you grant them.

Report privacy concerns through
[GitHub Issues](https://github.com/obselate/sharptui/issues).
