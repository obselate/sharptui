The direct native encoders use reusable storage. Kitty physical placement restoration failed the real popup screen comparison and was rejected. Unicode image placeholders passed exact restoration and use the same retained claims to compose image cells with text. A fixed protocol diacritic table is retained once. Text is invalidated only for changed claims or image geometry, and no glyph strings or snapshots are created per frame. The raster has the target pixel aspect ratio so Contain, Cover and Stretch preserve their stated semantics. Fully covered staged sources keep their bounded upload cache. Terminal rasters are deleted when draws leave the frame or when the backend changes. Native Kitty rectangles above 297 rows or columns fall back to half blocks. Auto Kitty mode requires a terminal supporting Unicode image placeholders, such as Kitty 0.28 or later. This passes the simplest allocation-free alternative gate before considering encoded snapshots. Decode is bounded to 16 MiB encoded and 64 MiB RGBA. Native frame raster budget is 4 million pixels, Sixel edges at most 8192, and logical image count at most 64. Video owns three maximum 1024 by 1024 RGBA buffers and a two-frame queue. Saturated producers replace complete frames instead of growing the queue. Pause and dispose stop owned processes and join readers. EOF ends playback and the completed reader remains owned until disposal. Player pause/resume reuses the buffers. A paused seek starts a bounded video-only decoder and publishes one preview frame before joining it. No audio starts for the preview. Seek and process construction remain rare, visible work. Test video Advance reports 0 UI-thread bytes over 1000 warmed polls.
